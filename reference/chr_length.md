# Pepper chromosome lengths

Lengths of pepper chromosomes 1-12 in a GRanges object. The genome for
which lengths were calculated (v1.55) was downloaded from
http://peppergenome.snu.ac.kr/download.php

## Usage

``` r
data(chr_length)
```

## Format

A GRanges object

## Examples

``` r
data(chr_length)
```
