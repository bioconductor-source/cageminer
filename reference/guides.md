# Guide genes associated with defense and resistance to oomycetes

The GO annotation was retrieved from PLAZA 4.0 Dicots.

## Usage

``` r
data(guides)
```

## Format

A data frame with genes in the first column and GO description in the
second column.

## References

Van Bel, M., Diels, T., Vancaester, E., Kreft, L., Botzki, A., Van de
Peer, Y., ... & Vandepoele, K. (2018). PLAZA 4.0: an integrative
resource for functional, evolutionary and comparative plant genomics.
Nucleic acids research, 46(D1), D1190-D1196.

## Examples

``` r
data(guides)
```
